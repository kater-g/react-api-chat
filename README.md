# Веб-мессенджер GREEN-API (в стилистике MAX)

Одностраничное веб-приложение (SPA) для отправки и получения сообщений WhatsApp через официальный шлюз GREEN-API. Интерфейс выполнен в стилистике мессенджера MAX с поддержкой адаптивной верстки для настольных компьютеров и мобильных устройств.

---

## Возможности приложения

- Авторизация по учетным данным инстанса (`idInstance`, `apiTokenInstance`) с предварительной проверкой статуса инстанса и настроек уведомлений.
- Создание новых диалогов по номеру телефона прямо из строки поиска (с автоматической нормализацией формата номера).
- Отправка текстовых сообщений адресату с отображением статусов доставки (отправлено, доставлено, прочитано, ошибка).
- Мгновенное получение входящих сообщений через технологию HTTP Long Polling.
- Поддержка синхронизации исходящих сообщений, отправленных с физического телефона или через сторонние API-запросы (`outgoingMessageReceived`, `outgoingAPIMessageReceived`).
- Межвкладочная синхронизация состояния через событие браузера `storage`.
- Сохранение истории переписки и активного диалога в `localStorage` с привязкой к конкретному идентификатору инстанса (данные сохраняются при перезагрузке страницы и повторном входе).

## Стек технологий

- **React** — пользовательский интерфейс без сторонних библиотек компонентов.
- **TypeScript** — строгая типизация данных, отсутствие типов `any`.
- **Vite** — быстрый инструмент сборки и локальной разработки.
- **CSS Modules** — модульные стили с изоляцией классов по методологии БЭМ.
- **HTML & WAI-ARIA** — семантическая верстка и доступность интерфейса (a11y) для скринридеров и навигации с клавиатуры.

## Предварительные требования к инстансу GREEN-API

Перед началом работы убедитесь, что ваш инстанс в личном кабинете GREEN-API подготовлен к работе в режиме Long Polling:

1. **Статус инстанса:** инстанс должен быть авторизован (в статусе `authorized`), а QR-код отсканирован в приложении WhatsApp на телефоне.
2. **Поле Webhook URL должно быть пустым:** приложение работает без собственного бэкенд-сервера и забирает сообщения напрямую через HTTP-опрос (Long Polling). Если в кабинете GREEN-API указан URL вебхука, сервис отключает очередь сообщений для браузера и возвращает ошибку. Убедитесь, что строка Webhook URL очищена.
3. **Настройки отправки уведомлений:** в разделе настроек инстанса должны быть включены:
   - Получать уведомления о входящих сообщениях (`incomingWebhook` = `yes`);
   - Получать уведомления о статусах доставки сообщений (`outgoingWebhook` = `yes`);
   - Получать уведомления о сообщениях, отправленных через API (`outgoingAPIMessageWebhook` = `yes`).

Приложение автоматически проверяет эти настройки при попытке входа и предупредит, если какая-то из них выключена.

## Локальный запуск проекта

### 1. Предварительные требования

Чтобы проект мог запуститься на вашем компьютере, должны быть заранее установлены:

- **Node.js** — среда выполнения JavaScript версии **18.0.0 или выше** (рекомендуется версия 20 LTS).  
  Проверить наличие и версию в терминале:
  ```bash
  node -v
  ```
- npm — пакетный менеджер (устанавливается автоматически вместе с Node.js) версии 9.0.0 или выше.
  Проверить версию в терминале:
  ```bash
  npm -v
  ```
- Git — система контроля версий для клонирования репозитория.

### 2. Клонирование и подготовка окружения

1. Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/kater-g/react-api-chat.git
cd react-api-chat
```

2. Создайте файл локальных переменных окружения .env из примера:

- В macOS / Linux:
  ```bash
  cp .env.example .env
  ```
- В Windows (CMD):
  ```DOS
  copy .env.example .env
  ```
- В Windows (PowerShell):
  ```PowerShell
  Copy-Item .env.example .env
  ```
(Либо создайте копию файла .env.example вручную в проводнике/редакторе кода и назовите её .env).

### 3. Установка зависимостей
Установите все необходимые библиотеки и пакеты, указанные в файле package.json:

  ```bash
  npm install
  ```
Команда скачает зависимости в папку node_modules и зафиксирует их версии.

### 4. Запуск приложения
Запустите локальный сервер разработки:

  ```bash
  npm run dev
  ```
После успешного выполнения команды в терминале появится локальный адрес. Откройте в браузере.
